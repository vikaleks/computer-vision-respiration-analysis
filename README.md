# Оценка частоты дыхания по видео с использованием MediaPipe и RAFT

## Описание проекта

Проект посвящён оценке частоты дыхания человека по видеозаписи с помощью методов компьютерного зрения.

В работе используется следующий подход:

- MediaPipe Pose Landmarker — для определения ключевых точек тела;
- выделение области грудной клетки;
- RAFT Optical Flow — для оценки движения грудной клетки между кадрами;
- обработка сигнала и поиск пиков для расчёта частоты дыхания.


## Этапы работы

### 1. Анализ видео

Из видео получаются основные параметры:
- частота кадров;
- количество кадров;
- разрешение;
- длительность.


### 2. Определение положения тела

MediaPipe определяет ключевые точки тела.

Для выделения области грудной клетки используются точки:
- плеч;
- таза.


### 3. Расчёт движения грудной клетки

RAFT Optical Flow оценивает движение пикселей между кадрами.

Из полученного движения выделяется вертикальная составляющая,
которая используется как дыхательный сигнал.


### 4. Обработка сигнала

Для улучшения качества сигнала выполняется:

- удаление тренда;
- фильтрация Баттерворта;
- поиск пиков дыхания.


## Эксперимент

Параметры видео:

- Длительность: 180.67 секунд
- FPS: 28
- Разрешение: 720×1280

Условия освещения:

- 0–57 сек — обычное освещение;
- 57–118 сек — слабое освещение;
- 118–180 сек — обычное освещение.


## Результаты

Ручной подсчёт:

- 90 дыханий;
- 29.89 дыханий/мин.


Результат алгоритма:

- найдено 84 пика;
- 27.90 дыханий/мин.


Абсолютная ошибка:

- 1.99 дыханий/мин.
